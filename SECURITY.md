# Security Policy

Please do not disclose security vulnerabilities directly in a public issue. Instead, use GitHub's **Report a vulnerability** feature if it is available for this repository.

Please include:

- the affected application version,
- the Windows version,
- reproducible steps,
- the expected and actual behavior,
- an assessment of the potential impact.

Do not include prompts, credentials, tokens, or other confidential information.

The Luna provider delegates authentication and token refresh to the official Codex App Server. Reports should never include Codex authentication files, OAuth callback URLs, access tokens, account email addresses, or raw App Server transcripts.
